# AGENTS.md, enfurl

enfurl is a stateless URL compressor that looks like a shortener: a furl is the whole URL rolled up losslessly, `furl.li` unfurls it and answers a 302, and nothing is stored, logged or looked up. One npm workspace (`enfurl-monorepo`, Node 22.18 or newer, TypeScript run directly through type stripping, so no enums, parameter properties or namespaces): `packages/codec` is `@enfurl/codec`, the codec and the frozen models, with zero runtime dependencies; `packages/cli` is the `enfurl` and `unfurl` commands; `apps/web` is the static furl.li page with its hand-written QR encoder; `apps/edge` is the Cloudflare Worker that serves the page and answers `GET /<furl>`; `tools/train` fetches corpora and trains models and is never shipped; `tools/qr-tables` regenerates the QR error-correction tables; `bench/` is the held-out benchmark behind every number in the README. `README.md` says what it is and why, `CONTRIBUTING.md` carries the one hard rule (a released model file never changes) and the style, `SECURITY.md` the attack surface. MIT, and the repository is public.

## How to see it

- Run: `node apps/web/build.mjs --serve` (`http://localhost:8787`, esbuild's dev server over `apps/web/public/` with `index.html` as the fallback for `/<furl>` paths; the `enfurl-web` entry in `.claude/launch.json`, a folder kept local through `.git/info/exclude`). The worker: `npm run dev -w apps/edge` (`wrangler dev`, port unverified). The CLI after a build: `node packages/cli/dist/cli.js <url>` (unverified; the README's `npx enfurl` form is the published package)
- Check, in the order `.github/workflows/ci.yml` runs them: `npm run typecheck` (`tsc -p packages/codec/tsconfig.json --noEmit`), `npm test` (`node --test` over `packages/codec/test/*.test.ts` and `apps/web/test/*.test.ts`: codec units against a toy model, the golden vectors against the real one, the range coder, and the QR encoder decoded by an independent decoder), `npm run build` (codec, cli, web, edge), then the frozen-model check: `git diff --quiet origin/main -- packages/codec/models/v1/model.json packages/codec/test/golden-v1.json` exits 0. `npm run bench` regenerates the README numbers and is not a check
- See the output with: browser through `.claude/launch.json` `enfurl-web`; the terminal for the tests and the CLI
- Verified means: the four CI steps pass locally with the golden vectors untouched, plus a person pastes a link at `http://localhost:8787`, sees the furl, its QR and the bit budget, and the `/#<furl>` form unfurls back to the same URL in the browser; for a worker change, `curl -sI` against `wrangler dev`, or against `https://furl.li/<furl>` after a deploy, shows a 302 with `Cache-Control: no-store` and `Referrer-Policy: no-referrer`, and `/<furl>+` shows the peek page instead of redirecting
- A check that was only written is not run. Paste the evidence table (what is guaranteed, command, result, evidence) in the closing message. No baseline: INCONCLUSIVE, never a silent pass.

## Human validation zones

Change nothing under a zone before stopping with: the zone name, what the change modifies or deletes, a one-line rollback, and the instruction quoted verbatim. Then wait for GO. Default zones apply everywhere, even when the table is empty: payments, spends and refunds, tenant scoping, wallet pass signing, backups, TR/EU credentials, production hosts, the deploy branch (merged means deployed), outward messages. Never run a mutating journey against production. Never parallelize migrations, same-table writes, or live deploys.

| Zone (path or action) | Why the cost of error is high | What Burak tests | How |
|---|---|---|---|
| `packages/codec/models/v1/model.json`, `packages/codec/test/golden-v1.json`, `packages/codec/src/format.ts` and the version list in `Codec` | A released model and its stream layout are frozen forever: a furl issued today must unfurl in twenty years. Any edit breaks every furl in the wild, and CI fails on a diff to the two files. Retraining, adding domains, fixing a phrase: all of it is a new `models/v2` directory and a new version entry, discussed in an issue first | `npm run test:golden` passes with the vectors untouched | `git diff origin/main -- packages/codec/models/v1/model.json packages/codec/test/golden-v1.json` is empty; `npm run test:golden` |
| `apps/edge/src/worker.ts`, `apps/edge/wrangler.toml`, and `npm run deploy -w apps/edge` (`wrangler deploy`) | A deploy goes straight to `furl.li`, production on a personal Cloudflare account, with nothing in between. The redirect must stay `http:` and `https:` only, `Cache-Control: no-store`, `Referrer-Policy: no-referrer`, with `blocked()` in the path, no binding beyond `ASSETS` and `[observability]` off | confirm with Burak | `curl -sI https://furl.li/DiIeQJCA` answers 302 with both headers; `https://furl.li/DiIeQJCA+` shows the peek page; `https://furl.li/` serves the app |
| Anything that stores or logs a furl or its target: analytics, click counts, custom aliases, request logging, a KV or D1 binding, `[observability]` | Architecturally out (`CONTRIBUTING.md`). The privacy property is the product, and it is verifiable by reading the code rather than a policy | confirm with Burak | `wrangler.toml` declares no binding beyond `ASSETS` and keeps `[observability] enabled = false`; `worker.ts` writes nothing anywhere |
| `dependencies` in `packages/codec/package.json` | `@enfurl/codec` ships with zero runtime dependencies, which the README badge, the library section and `CONTRIBUTING.md` all promise; the QR encoder was written by hand for the same reason | The key stays absent | `git diff packages/codec/package.json` |
| Every commit and push: the repository is public | Anything committed is public, and a pushed commit stays reachable by its SHA even after a force-push. A local-only folder, a corpus under `bench/corpus/` or `tools/train/`, or anything kept out through `.git/info/exclude` must never ride along | confirm with Burak | `git status --porcelain` before a commit lists only the intended files; `.gitignore` and `.git/info/exclude` still cover the local folders |
